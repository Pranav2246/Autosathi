# AutoSathi Online
Static frontend demo for online rickshaw booking.

## Deploy
Upload these files to a GitHub repository. Enable Settings → Pages → Deploy from a branch → main → /(root). GitHub Pages publishes static files.

## Important
This version intentionally does not use localhost, MongoDB, a backend server, or secret Razorpay keys. Booking is a browser-side demo using localStorage. For real bookings/payments, add a separately hosted backend/API and payment gateway integration.
